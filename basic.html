HTML Lists

There are three types of lists.

Unordered Lists

Unordered lists have bullet points to the left of each list item. These lists are contained in a <ul> tag. Each item in the list is contained in an <li> tag.

  • Kaleb
  • Cedric
  • Ian
  • Alex
  • Levi
  • Martin
  • Angus

Note: Unordered lists are the base HTML structure used to create navigation.

Ordered Lists

Ordered lists are used to create a sequence of items. List items have a number, Roman numeral, or alphabetic character to the left of each item. Like unordered list items, ordered list items are contained in <li> tags.

  1. Step 1: Crack eggs
  2. Step 2: Add milk
  3. Step 3: Whisk eggs and milk
  4. Step 4: Pour into a hot pan
  5. Step 5: Stir until done

Anchor Tags

An anchor element defines a hyperlink in a webpage. A hyperlink, or link, specifies where other information is located and what action the web browser should perform when a user clicks the hyperlink.

The <a> tag by itself is not useful without the href attribute. Href is short for hyperlink reference. When a link takes you away from your website, you can open it in a new browser tab.

Absolute and Relative URLs

URL: Universal Resource Locator, otherwise known as a web address.

Absolute URL: A complete URL including the transfer protocol. Example:
https://resources.zybooks.com/WebProgramming/mediumCatv1.jpg

Relative URL: A path to a web resource with no scheme or hostname (protocol or domain). Relative URLs refer to resources based on the current web address. Examples:
/img/cyber-hero23.webp or index.html

Section Links

A URL can point to a section, or fragment, of a document by adding a hash symbol (#) and a fragment identifier at the end of the URL.

Example:
example.com#paragraphs

The section listed after the # refers to an id attribute. For example:
<section id="paragraphs">. The id attribute creates a fragment identifier.
